══════════════════════════════════════════════════════════════
  NOTATION DANIELS — FORMAT & RÈGLES
══════════════════════════════════════════════════════════════

La nomenclature Daniels a 4 groupes séparés par / ou - :
  Bois / Cuivres / Percussions / Cordes

Format Bois :     Fl.Hb.Cl.Bn  (ex: 2.2.2.2)
Format Cuivres :  Cor.Tp.Tb.Tuba (ex: 4.2.3.1)
Format Percussions : Timb.Perc.Hp.Clav [spécification claviers]
  → Le format est W.X.Y.Z où :
    W = nombre de Timbaliers
    X = nombre de Percussionnistes (hors timbalier)
    Y = nombre de Harpes
    Z = nombre de Claviers (Célesta, Piano, etc.)
  → Les crochets [Cel/Pno] précisent quels claviers
Format Cordes :   Vl1.Vl2.Alt.Vlc.CB (ex: 14.12.10.8.6)

⚠️ VARIANTES DE FORMAT :
- Séparateur POINTS : 2.2.2.2 / 4.2.3.1 / 1.0.0.0 (standard symphonique)
- Séparateur TIRETS : 0-1-0-1 / 0-2-0-0 / 1-0-0-2 (fréquent en musique baroque/ancienne)
- Séparateur SLASH entre groupes : 2.2.2.2/4.2.3.1/1.0.0.0
- Mixte : tirets dans un groupe, points dans un autre → normaliser en points dans le JSON

Quand tu lis la notation, repère d'abord le séparateur utilisé (points ou tirets) puis décode chaque groupe.

══════════════════════════════════════════════════════════════
  RÈGLES CRITIQUES POUR LES PERCUSSIONS
══════════════════════════════════════════════════════════════

Le champ "percus" est un tableau de PÔLES (postes de travail). Chaque pôle a un nom et une liste d'instruments.

⚠️ DISTINCTION TIMBALIER vs PERCU — C'EST CRUCIAL :
- Le "Timbalier" (ou "Timb") est un poste SÉPARÉ. Marqué "Timb" ou "Timbalier" sur le plan.
- Il peut y avoir PLUSIEURS timbaliers (Timbalier 1, Timbalier 2) si la nomenclature l'indique.
- Le timbalier ne contient QUE des timbales + éventuellement 1-2 petits accessoires à côté (triangle, tambourin).
- Les "Percu 1", "Percu 2", etc. (ou "P1", "P2") sont les AUTRES percussionnistes. Ils jouent claviers, cymbales, tam-tam, grosse caisse, caisse claire, accessoires.
- NE JAMAIS mettre les instruments de Percu dans le Timbalier ni l'inverse.

⚠️ COMPTAGE DES TIMBALES — CRITIQUE :
- 1 timbale = 1 instrument individuel. Chaque timbale est un item séparé.
- Le nombre de timbales varie : 0, 2, 3, 4 ou 5 selon la pièce. Lire la nomenclature ou compter sur le plan.
- Si la nomenclature indique 0 timbales ou qu'aucun timbalier n'est visible sur le plan, NE PAS créer de pôle Timbalier.
- NE PAS écrire un seul item "4 Timbales". Écrire N items séparés : "Timbale 1", "Timbale 2", etc.
- Si les tailles sont visibles sur le plan, les indiquer : "Timbale 32\"" etc. Sinon numéroter simplement.

Exemple avec 4 timbales :
"percus": [
  {"nom": "Timbalier", "items": [
    {"cat": "Timbales & Peaux", "nom": "Timbale 1"},
    {"cat": "Timbales & Peaux", "nom": "Timbale 2"},
    {"cat": "Timbales & Peaux", "nom": "Timbale 3"},
    {"cat": "Timbales & Peaux", "nom": "Timbale 4"}
  ]},
  {"nom": "Percu 1", "items": [{"cat": "Claviers", "nom": "Vibraphone"}, {"cat": "Claviers", "nom": "Xylophone"}, {"cat": "Grosses pièces", "nom": "Tam-tam"}]},
  {"nom": "Percu 2", "items": [{"cat": "Claviers", "nom": "Marimba"}, {"cat": "Accessoires", "nom": "Triangle"}, {"cat": "Timbales & Peaux", "nom": "Caisse claire"}]}
]

Catégories d'instruments : "Claviers", "Timbales & Peaux", "Accessoires", "Grosses pièces", "Stands & supports", "Baguettes & spécial"

══════════════════════════════════════════════════════════════
  NOTATION DANIELS PERCUSSIONS CHIFFRÉE (W.X.Y.Z)
══════════════════════════════════════════════════════════════

Le 3e groupe de la nomenclature Daniels encode les percussions :
  W.X.Y.Z  =  Timbalier(s) . Percussionniste(s) . Harpe(s) . Clavier(s)

Exemples :
  1.0.0.0  → 1 Timbalier, 0 percussionnistes, 0 harpe, 0 clavier
  1.3.1.1  → 1 Timbalier, 3 percussionnistes, 1 harpe, 1 clavier
  0.2.1.0  → 0 Timbalier, 2 percussionnistes, 1 harpe, 0 clavier
  1.0.0.2  → 1 Timbalier, 0 percussionnistes, 0 harpe, 2 claviers (orgue+clavecin, etc.)

Utilise ce décodage pour :
1. Savoir combien de pôles Timbalier créer (W=0 → aucun pôle Timbalier)
2. Savoir combien de pôles Percu créer (X postes)
3. Placer Y harpe(s) dans orchestre.autres
4. Placer Z clavier(s) dans orchestre.autres (avec la spécification entre crochets [Cel/Pno] si présente)

══════════════════════════════════════════════════════════════
  ORCHESTRE / CLAVIERS / CONTINUO
══════════════════════════════════════════════════════════════

RÈGLES ORCHESTRE / CLAVIERS :
- Les crochets [Cel/Pno] ou [Cel] ou [Piano/Célesta] indiquent des claviers supplémentaires REQUIS → orchestre.autres.
- Si tu vois [Cel/Pno], mets "Célesta" ET "Piano" dans orchestre.autres.
- Harpe (Hp) va aussi dans orchestre.autres.

CONTINUO (musique baroque / ancienne) :
- Si le plan mentionne un continuo ou basse continue, remplir orchestre.continuo.
- Instruments typiques de continuo : Orgue, Clavecin, Théorbe, Luth, Viole de gambe, Violone.
- Le continuo est distinct des cordes et des claviers solistes.
- Exemple : orchestre.continuo = ["Orgue", "Clavecin", "Théorbe"]

══════════════════════════════════════════════════════════════
  STRATÉGIE CONTEXTUELLE PAR STYLE MUSICAL
══════════════════════════════════════════════════════════════

Adapte ton interprétation au style musical détecté :

🎻 BAROQUE (avant ~1750 : Bach, Haendel, Purcell, Rameau, Lully)
- Pas de notation Daniels standard → utilise tirets si visible, sinon décris l'effectif
- Orchestre = continuo + cordes (souvent en 5 parties)
- Cordes baroques : Dessus (= Violon I), Tailles (= Violon II ou Alto), Viole (= Alto ou Viole de gambe), Violone (= Basse/Violoncelle), Contrebasse
- Vents possibles : Hautbois, Flûtes à bec, Trompettes naturelles
- Percussions rares : timbales baroques uniquement
- Claviers : Orgue, Clavecin (dans le continuo, PAS dans orchestre.autres)
- SI tu vois "Dessus", "Tailles", "Viole", "Violone" → les GARDER tels quels, ne PAS traduire en termes modernes

🎼 CLASSIQUE (1750-1830 : Haydn, Mozart, Beethoven 1-6)
- Notation Daniels standard avec points
- Orchestre type : 2.2.2.2 / 2.2.0.0 / 1.0.0.0 - cordes
- Peu de percussions (Timbalier seul, max 1 Percu)
- Pas de tuba, pas de trombone (sauf Beethoven tardif)

🎵 ROMANTIQUE (1830-1910 : Brahms, Mahler, Wagner, Strauss, Tchaïkovski)
- Notation Daniels standard, effectifs plus gros
- Orchestre type : 3.3.3.3 / 4.3.3.1 / 1.3.2.1 - 16.14.12.10.8
- Harpe(s), célesta, piano possibles
- Percussions variées et nombreuses

🔊 CONTEMPORAIN / CRÉATION (après 1950 : musique spectrale, IRCAM, création)
- Nomenclature parfois non-standard ou absente
- Électronique possible (IRCAM, live electronics) → noter dans orchestre.autres
- Instruments préparés, techniques étendues
- Percussions souvent très développées avec setups spéciaux
- Si le plan mentionne "électronique", "IRCAM", "live electronics" → ajouter dans orchestre.autres

══════════════════════════════════════════════════════════════
  DÉSAMBIGUÏSATION "Cel" — CONTEXTE CRUCIAL
══════════════════════════════════════════════════════════════

- Dans la nomenclature Daniels entre crochets [Cel] ou [Cel/Pno] → "Cel" = CÉLESTA (clavier à lames)
- Comme label sur le plan PRÈS DES CORDES → "Cel" peut être Violoncelle (= Cello)
- Abréviations Violoncelle : Vlc, Vc, Cello, Cel (si près des cordes)
- Abréviations Célesta : Cel (si dans les crochets ou près des claviers/percussions), Célesta, Celesta
- VÉRIFIER LE CONTEXTE : position sur le plan + nomenclature. Si "Cel" est écrit à côté du piano/percussions = Célesta. Si c'est dans la section cordes = Violoncelle.
