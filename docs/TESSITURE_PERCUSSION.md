# OrkMap — Base de tessiture des instruments de percussion

Sources : **Kolberg Tonumfangtabelle** (référence primaire), Adams, Bergerault, Yamaha, Rythmes & Sons, Paiste.
Notation : scientifique (C4 = do central, A4 = la 440 Hz).
Notation allemande Kolberg : c = C4, c¹ = C5, c² = C6, c³ = C7, C = C2, etc.

> **⚠️ La Tonumfangtabelle Kolberg est LA référence mondiale** pour les tessitures percussion.
> Poster mural A1 disponible dans `docs alex regie/Tonumfangtabelle_A1-Kolberg.pdf`.

## Utilisation dans OrkMap

### Pour l'extraction IA
Quand l'IA identifie un instrument à sons déterminés, elle doit noter la TAILLE (en octaves ou en pouces) car ça détermine la tessiture. Un "marimba" sans précision est insuffisant — il faut "marimba 5 oct" ou "marimba 4⅓ oct".

### Pour la vérification de partitions (Phase 4)
L'agent vérificateur compare chaque note de la partition avec la tessiture de l'instrument spécifié :
- **Vert** : note dans la tessiture normale
- **Orange** : note dans l'extrême de la tessiture (possible mais difficile)
- **Rouge** : note HORS tessiture (erreur du compositeur ou instrument mal spécifié)

Exemple : si la partition demande un La1 (A1) au marimba et que l'orchestre a un marimba 4⅓ oct (A2–C7), c'est vert. Mais si c'est un marimba 4 oct (C3–C7), c'est ROUGE — il faut un 5 oct.
